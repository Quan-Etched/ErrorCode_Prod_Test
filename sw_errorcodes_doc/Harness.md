## TH-ENV-0001: HOST_NOT_REACHABLE_AFTER_BOOT

### 标识

| 字段 | 值 |
| --- | --- |
| 错误码 | `TH-ENV-0001` |
| 名称 | `HOST_NOT_REACHABLE_AFTER_BOOT` |
| 版本 | 1 |
| 起始版本 | harness 2026.216 |
| 负责人 | supercomputing-sw |
| Jira 组件 | ETCH / MLT |

### 分类

| 字段 | 值 |
| --- | --- |
| 类别 | 1 — 网络 |
| 严重级别 | 4 — 分诊 |
| 快速处置 | 9 — 升级 |
| 处置结果 | 错误 |
| 组件 | `1X.ENV.STATION_HOST` |
| 可重试 | False |
| 最大自动重试次数 | 0 |

### 描述

工位主机或其 BMC 在启动后未响应 ping 或 SSH，因此无法启动任何模块测试。这是测试系统状态问题，不是模块判定结果。

### 测试用例

_无_

### 可能原因

- 工位主机已关机，或卡在操作系统起来之前
- BMC 网络或管理线缆故障
- 工位主机上 sshd 未运行，或主机密钥已变更
- 工位主机 IP/DHCP 预留已变更

### 采集项

- suite_run_url
- 工位主机及其 BMC 的 ping 与 ssh 记录
- station_id, harness_version, operator_id, timestamp

### 维修措施

| 步骤 | 执行者 | 措施 | 复测 | 预计时间（分钟） | 停止条件 |
| --- | --- | --- | --- | --- | --- |
| 1 | 操作员 | 将显示器接到 Devkit，确认系统能成功启动，然后尝试对主机 / BMC 执行 ping。 |  |  | — |
| 2 | 操作员 | 收集本次失败的套件/测试日志与产物。 |  | 5 | — |
| 3 | 升级处理 | 将收集到的日志升级给 Etched 工程师。 |  |  | — |

### 疑似组件

_无_

### 供应商错误 ID

_无_

### 描述

### 测试用例

_无_

- DUT 在测试工作负载下挂起或严重变慢

- Harness/执行器停滞（例如远程连接丢失）

### 采集项

- suite_run_url
- per-test log and transcript
- 已配置的超时时间与实测持续时间
- harness_version, station_id, operator_id, timestamp
